How it works

  1. The user provides a target and TCP port.
  2. Python opens a TCP socket and attempts a connection with a timeout.
  3. The application reports Open, Closed, Timeout, or Error and records elapsed time.

This checks TCP connection availability, not UDP ports or whether an application is functioning correctly.
